## Project Overview
This professional Data Science portfolio demonstrates an end-to-end Machine Learning pipeline. It includes data ingestion, exploratory data analysis (EDA), model comparison using cross-validation, and a deployment-ready web application.

## Contents
1. **main.ipynb**: The core Jupyter Notebook containing the data science workflow, statistical analysis, and model validation.
2. **app.py**: A Streamlit web application that serves the model, allowing users to input flower measurements and receive real-time predictions.
3. **iris_data.csv**: The dataset used for training.
